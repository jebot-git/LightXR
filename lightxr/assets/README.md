# OpenXR greeter background

`openxr-login-background.png` was generated for this project with OpenAI's image
generation tool on 2026-10-20, following the request for an OpenXR login background.
It is original generated artwork, not a downloaded CC0 photograph. The embedded
wordmark reads OpenXR; OpenXR is a Khronos Group trademark. The artwork does not
claim Khronos endorsement. Login controls and their opaque backing are native Qt
widgets, rendered separately from the image. There are no credentials in the asset.

The composition reserves its right half for the authentication card and its lower
half for the on-screen keyboard. Qt embeds this image in the greeter executable,
so there is no runtime download or dependency on a user's home directory.
